# 🎭 ChaCha — Minimal AI Charades

A dead-simple charades / "Heads Up"-style game for the car. Pick a category,
hold the phone up so everyone else can see the word, and act it out. Landscape
only, built for phones.

- **Swipe up** = skip the word
- **Swipe down** = got it! (score +1)
- 60-second timed rounds, then a score + results screen
- Word decks are **AI-generated at build time** and served as plain static files,
  so gameplay works even with a spotty signal on the road

The site is a plain static page (vanilla HTML/CSS/JS — no build step) hosted on
**GitHub Pages**. Word decks are generated by a GitHub Action using the Claude
API. **The API key lives only in CI and is never shipped to the browser.**

## How word generation works

GitHub Pages serves only static files — there is no server at runtime, and a
GitHub secret is only available during a Actions build. So AI generation happens
at **build time**:

1. `categories.json` lists the categories.
2. The **Generate decks** workflow runs `scripts/generate.mjs`, which asks Claude
   for ~40 words per category and writes `decks/<slug>.json`.
3. Those decks are committed and deployed as static files. The browser just
   fetches them.

Trade-off: adding a category is not instant. You edit `categories.json` and
re-run the generate action (~1 minute), rather than creating one live at runtime.

## One-time setup

1. **Add the API key secret.** Repo → Settings → Secrets and variables → Actions
   → New repository secret:
   - Name: `ANTHROPIC_API_KEY`
   - Value: your Claude API key
2. **Enable Pages.** Repo → Settings → Pages → Build and deployment → Source:
   **GitHub Actions**.
3. Push to the `claude/charades-game-mvp-eg3u8g` branch (or run the **Deploy to
   GitHub Pages** workflow manually). The game goes live at:

   ```
   https://leohchen.github.io/ChaCha/
   ```

Seed decks are already committed, so the game is playable the moment Pages is
enabled — even before the generate action has ever run.

## Adding or changing a category

1. Edit `categories.json` (add/rename a category).
2. Run the **Generate decks** workflow (Actions tab → Generate decks → Run
   workflow). It generates any missing decks and commits them, which triggers a
   redeploy.
   - To regenerate everything from scratch, run it with **force** checked.

## Running locally

Play the game locally against the seed decks — no key needed:

```bash
npm run serve        # serves the current folder at http://localhost:8000
```

Open it in a browser, switch to a landscape phone in the device toolbar, and use
the **Arrow Up / Arrow Down** keys to skip / mark got-it on desktop.

Regenerate decks locally (needs a key):

```bash
npm install
ANTHROPIC_API_KEY=sk-... npm run generate            # only missing decks
ANTHROPIC_API_KEY=sk-... node scripts/generate.mjs --force   # all decks
```

## Project layout

```
index.html                    # single page: orientation gate, menu, game, results
styles.css                    # minimal landscape-only styling
app.js                        # deck load, timer, score, swipe gestures
categories.json               # the category list (generator input)
decks/<slug>.json             # pre-generated word decks (committed)
scripts/generate.mjs          # Claude-powered deck generator
.github/workflows/generate-decks.yml   # build decks (uses the secret)
.github/workflows/deploy.yml           # publish to GitHub Pages
```
